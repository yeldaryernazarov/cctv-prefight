# Testing Guide

## Функциональное тестирование

### 1. Подключение камеры

**Цель**: Проверить стабильное подключение к RTSP камере

**Шаги**:
1. Добавьте камеру через админ-панель с валидным RTSP URL
2. Проверьте статус камеры - должен быть "online"
3. Оставьте систему работать 2 часа без ручного рестарта

**Критерий приёмки**: Камера остается online 2+ часа

---

### 2. People Detection & Tracking

**Цель**: Проверить детекцию и трекинг людей

**Тестовый сценарий**:
- 3-10 людей в кадре
- Движение людей в разных направлениях
- Люди пересекают друг друга

**Шаги**:
1. Запустите видео с тестовым сценарием
2. Наблюдайте за треками в системе
3. Проверьте, что треки сохраняют ID при временных окклюзиях

**Критерий приёмки**: Треки остаются стабильными без частых "прыжков" ID

---

### 3. PROXIMITY_RISK Detection

**Цель**: Проверить обнаружение близкого сближения

**Тестовый сценарий**:
- 2 человека быстро сближаются
- Расстояние становится < 1.5 метра
- Длительность >= 2 секунды

**Шаги**:
1. Воспроизведите тестовый сценарий на камере
2. Проверьте, что система генерирует PROXIMITY_RISK событие
3. Повторите 10 раз

**Критерий приёмки**: 8/10 тестов успешны (80% detection rate)

---

### 4. CROWD_RISK Detection

**Цель**: Проверить обнаружение скопления людей

**Тестовый сценарий**:
- 5+ людей собираются в зоне ROI
- Высокая плотность людей
- Длительность >= 3 секунды

**Шаги**:
1. Воспроизведите тестовый сценарий
2. Проверьте, что система генерирует CROWD_RISK событие
3. Повторите 10 раз

**Критерий приёмки**: 8/10 тестов успешны (80% detection rate)

---

### 5. Alert Aggregation

**Цель**: Проверить агрегацию событий в алерты

**Тестовые кейсы**:

**Кейс A**: Одиночное слабое событие
- Результат: НЕ должен создавать Alert

**Кейс B**: Серия событий в окне времени
- 3+ события в течение 20 секунд
- Результат: ДОЛЖЕН создать Alert

**Критерий приёмки**: Оба кейса проходят успешно

---

### 6. Guard UI - Alert Response Time

**Цель**: Проверить скорость доставки алертов до UI

**Шаги**:
1. Сгенерируйте риск-событие
2. Засеките время до появления алерта в UI
3. Повторите 10 раз

**Критерий приёмки**: 
- Средняя задержка <= 5 секунд
- 90% алертов приходят в течение 5 секунд

---

### 7. Clip Saving & Playback

**Цель**: Проверить сохранение и воспроизведение клипов

**Шаги**:
1. Дождитесь алерта с событием
2. Откройте карточку алерта
3. Проверьте, что клип воспроизводится
4. Проверьте, что клип содержит 10 сек до и 10 сек после события

**Критерий приёмки**: 
- Клип открывается и воспроизводится
- Длительность клипа ~20 секунд

---

### 8. Guard Decision Workflow

**Цель**: Проверить workflow принятия решений охранником

**Шаги**:
1. Откройте алерт
2. Просмотрите клип
3. Добавьте комментарий
4. Нажмите "Confirm"
5. Проверьте, что решение сохранено в БД

**SQL проверка**:
```sql
SELECT * FROM alert_decisions 
WHERE alert_id = '<alert_id>' 
ORDER BY timestamp DESC LIMIT 1;
```

**Критерий приёмки**: Решение сохраняется в БД с правильными данными


**Критерий приёмки**: Логи пишутся, нет критических ошибок

---

### 10. Camera Offline Detection

**Шаги**:
1. Отключите сетевой кабель от камеры
2. Проверьте, что система детектирует offline статус
3. Подключите кабель обратно
4. Проверьте автопереподключение

**Критерий приёмки**: 
- Offline детектируется в течение 30 секунд
- Автопереподключение происходит без ручного вмешательства

---

### 11. Clip Retention

**Шаги**:
1. Установите retention в 1 день (для теста)
2. Создайте тестовый алерт с клипом
3. Измените created_at на 2 дня назад (SQL)
4. Запустите cleanup функцию

**SQL**:
```sql
-- Update test alert
UPDATE alerts SET created_at = NOW() - INTERVAL '2 days' 
WHERE id = '<test_alert_id>';

-- Run cleanup
SELECT cleanup_old_clips();

-- Check if deleted
SELECT * FROM alerts WHERE id = '<test_alert_id>';
```

**Критерий приёмки**: Старые клипы удаляются автоматически

## Типичные проблемы и решения

### Проблема: Много ложных срабатываний

**Решение**:
1. Настройте зоны (ROI) - исключите фоновое движение
2. Увеличьте пороги в Settings
3. Используйте schedule profiles

### Проблема: Низкий detection rate

**Решение**:
1. Проверьте качество видео (разрешение, FPS)
2. Убедитесь, что люди не слишком маленькие в кадре
3. Уменьшите пороги в Settings

### Проблема: Высокая латентность

**Решение**:
1. Используйте substream для аналитики
2. Уменьшите количество камер на сервере
3. Проверьте сетевую задержку до камер
